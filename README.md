# سایت مَن با دیتابیس مرکزی

## قابلیت‌ها
- شماره جدید + رمز: ساخت حساب در PostgreSQL
- شماره تکراری + رمز درست: ورود به حساب قبلی
- شماره تکراری + رمز اشتباه: رد ورود
- پنل مدیریت: نمایش شماره‌ها و زمان ثبت‌نام
- رمز کاربران با scrypt هش می‌شود و رمز خام ذخیره یا نمایش داده نمی‌شود.
- رمز مدیریت از متغیر محیطی `ADMIN_PASSWORD` خوانده می‌شود و در HTML نیست.

## اجرای محلی
به Node.js نسخه 20 یا جدیدتر و یک دیتابیس PostgreSQL نیاز دارید.
متغیرهای محیطی:
- `DATABASE_URL`: آدرس اتصال دیتابیس
- `ADMIN_PASSWORD`: رمز پنل مدیریت (می‌توان مقدار `AMX_AMX` گذاشت)

سپس:
```bash
npm install
npm start
```
سایت در `http://localhost:3000` باز می‌شود.

## انتشار
این نسخه روی GitHub Pages اجرا نمی‌شود؛ چون GitHub Pages فقط فایل استاتیک میزبانی می‌کند.
باید پروژه روی میزبان Node.js مثل Render منتشر و به PostgreSQL متصل شود.
در Render، Build Command برابر `npm install` و Start Command برابر `npm start` باشد.
`DATABASE_URL` و `ADMIN_PASSWORD` را در Environment تنظیم کنید و دیتابیس PostgreSQL پایدار متصل کنید.

## توجه
این نسخه فعلاً پیامک OTP ارسال نمی‌کند؛ ورود با شماره و رمز است. برای کد پیامکی باید سرویس پیامک و API معتبر اضافه شود.
